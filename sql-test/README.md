# Test SQL (SQL Server)

Le query da analizzare sono in `esercizio.sql`. Struttura e dati sono in `setup.sql`.

Per eseguirle online: apri [db<>fiddle](https://dbfiddle.uk), scegli **SQL Server 2022** dal menu in alto, incolla `setup.sql` nel primo riquadro e `esercizio.sql` nel secondo. Poi premi **Run**.

Rispondi alle domande 1 e 2 **prima** di eseguire le query.

Segnalazioni dell'utente:

- "Il fatturato 2025 di Rossi risulta 350 €, ma i suoi ordini valgono 150 €."
- "La lista dei clienti senza ordini è vuota, ma Bianchi non ha mai ordinato."

1. Perché il fatturato di Rossi è sbagliato?
2. Perché la seconda query non restituisce nessun cliente?
3. Con milioni di ordini la prima query è lenta. Perché, e cosa cambieresti?

Ragiona ad alta voce. Puoi modificare le query e rieseguirle.
